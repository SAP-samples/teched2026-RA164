# Getting Started

## Access the SAP Document AI User Interface

Open the URL provided by your session facilitator. Log in with the credentials on your desk card.

You will land on the SAP Document AI home screen. The tiles give you access to all major features. In this session you will use **Manage Schemas** and **Manage Workflows**.
